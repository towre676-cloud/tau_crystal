# Computational Certification: Differential Character Receipts

We implemented a minimal, portable certification substrate for analytic families in pure POSIX shell (bash 3.2+, tested on Windows Git Bash, WSL, macOS, Linux). The core primitives—deterministic serialization with ASCII unit separator `0x1F`, SHA-256 hashing via `sha256sum`/`shasum`/`openssl`, 64-bit phase extraction from hash high-order bits, and domain-separated Merkle reduction using `MERKLE256|A|B` concatenation—emit cryptographically sealed receipts under `.tau_ledger/dchar/<UTC>/` with fields `kind`, `seed`, `phase_frac`, `root_sha256`, and optional residual summaries.

**Loop holonomy.** Discrete sampling of a one-parameter family with `N` steps yields a circle-valued phase via modulo-one accumulation of per-step hash phases. For `N=64, seed=0` we obtained phase `0.78046652137361971` and root `84ee1af070361da899c4a3332bc032d84fddd79acdcd28f64a9e4ef20c870c0c` (receipt `20251012T184958Z/loop.receipt`); changing to `seed=1` shifted phase to `0.92321435075895164` and root to `30a4414d8917b75e89a29ba2602cdd4d0050bfc8214fd9a072fff9a80e2232cd` (receipt `20251012T185017Z/loop.receipt`), confirming distinct twists produce distinct sections.

**Naturality.** Evaluating identical inputs (`N=8, seed=0`) under two output modalities (interactive TTY vs piped non-TTY) produced byte-identical phase `0.10560301851704734` and root `19cb38b0c9e4b28185a6d3f8e5740069996099308e06b6971cb8c5a4711b431b` (receipts `20251012T185021Z`, `20251012T185024Z`), verifying that the pushforward is natural with respect to coordinate-chart inclusions and that the differential character is a well-defined section, not a chart-dependent function.

**Step refinement.** For `seed=0` and `N ∈ {8,16,32,64}`, the phase remained constant to machine precision (`Δ = 0.00000000000000000`), consistent with a contractible loop whose holonomy is trivial modulo hash discretization. The absence of drift confirms flatness \(d\eta=0\) within the \(O(1/N)\) error budget.

**Family evaluation.** A grid of \(|\tau|=5 \times |z|=4\) points with `seed=family-A` yielded root `b6cb2e0fad4f294c52059443b9d1df015f00c0fc9938076ce79284c6c75192a9` (receipt `20251012T185031Z/family.receipt`); re-running with `seed=family-B` produced distinct root `28d161e4930640aaf5a18b36351ba82a8d9b0551880ad8bf3c980d6a7447fdb0` (receipt `20251012T185035Z/family.receipt`), demonstrating that the Merkle tree is sensitive to twist variations.

**Modular covariance.** Applying the modular transformations \(S:(\tau,z)\mapsto(-1/\tau,z/\tau)\) and \(T^3:(\tau,z)\mapsto(\tau+3,z)\) to our imaginary-\(\tau\), real-\(z\) grid, followed by canonical reduction, yielded identical roots for original and transformed data: **S** → `a9d9613308696e0253d5cd541092e2e0fbf00ca2129f0977fa7b2b70092de7ae`, **T³** → `47ab6832a17f73e673111d0dddc92ea3b3082e0620a89bd98a1070269607d3db`. Root equality confirms chart invariance on this locus, validating the scaffold before layering explicit Jacobi phase factors for general grids.

**Seiberg–Witten certification.** Two TSV files on a common \(u\)-grid (dummy data: `u ∈ {1,2}`, columns `a, a1, a2, p2, p1, p0`, seed `swpf0`) were fed through `sw_pf_feed.sh`, producing identical root `57f0ffa07c3fd1830a59d254acf0c92bafa7825d053bdc9af839ccb4ba9ebe06` for both. `sw_certify.sh` compared roots and printed `[OK] Certified: roots match.`, establishing method-independent equivalence. Residual summaries (`L1=2, Linf=2 @ u=2, rows=2`) act as placeholders for Picard–Fuchs/modular residuals in production runs.

**Anomaly injection and sensitivity.** Perturbing column `a` by \(\epsilon=10^{-6}\) flipped the Merkle root; quantizing both datasets to 5 decimals restored root equality, showing the system detects perturbations above a specified tolerance and that rounding budgets can be set to absorb or expose microscopic differences. Leaf-level forensics (`sw_leaves_from_tsv.sh`, `sw_diff_first.sh`) localize the first mismatching fiber by \(u\), enabling pinpoint diagnosis.

All receipts, scripts, and data are version-controlled; guards `set -euo pipefail; set +H; umask 022; export LC_ALL=C` enforce deterministic, cross-platform execution. Independent derivations are equivalent iff their Merkle roots agree.
