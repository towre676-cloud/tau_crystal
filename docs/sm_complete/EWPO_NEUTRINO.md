# Electroweak Mass Matrix & Neutrino Modes

## Electroweak Mass Matrix
- Higgs VEV: ⟨Φ⟩ = (0, v/√2)^T
- Gauge fields mixing: (Z_mu, A_mu)^T = [[cosθ_W, -sinθ_W], [sinθ_W, cosθ_W]] (W^3_mu, B_mu)^T
- Masses: m_W = gv/2, m_Z = v/2 sqrt(g^2 + g'^2), m_γ = 0
- Coupling: e = g sinθ_W = g' cosθ_W

## Neutrino Sector Toggle
- Dirac: standard Yukawa coupling with right-handed neutrino
- Weinberg/Majorana: dimension-5 operator (LLHH/Λ)
- Toggle controlled by NEUTRINO_TOGGLE.txt
