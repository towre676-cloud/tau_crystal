# Normalization Manifest (v1)
Fields (canonical keys, UTF-8, LF):
- scheme: e.g. MSbar
- mu_GeV: e.g. 91.1876
- pdf_set: e.g. NNPDF4.0_nnlo_as_01180
- alpha_s_MZ: value ± err
- ew_inputs: { G_F, M_Z, M_W(optional), sin2theta_eff, α(0) or α(M_Z) }
- lattice: { action, a_fm, volume, m_pi, extrapolation } (if used)
- resummation: { accuracy, formalism } (if used)
- uncertainties: { stat, syst, theory } with definitions
- notes: free text (≤2k chars)
